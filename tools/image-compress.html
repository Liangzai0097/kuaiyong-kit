常见问题

我的图片会上传到你们服务器吗？

不会。整个压缩过程使用浏览器自带的 Canvas API 在你本地完成，图片不会发送到任何服务器，断网也能用。

支持批量压缩吗？

当前版本仅支持单张压缩，批量功能正在开发中。

为什么 PNG 压缩效果不明显？

PNG 是无损压缩格式，调节"压缩质量"对它影响很小。如果需要显著减小体积，建议输出格式选 JPEG 或 WebP。

WebP 是什么？

WebP 是 Google 推出的图片格式，相同画质下体积比 JPEG 小 25%-35%，主流浏览器都已支持，是网页图片的首选。

图片有大小限制吗？

理论上没有限制，但浏览器内存有限，建议单张不超过 50MB，否则可能压缩失败或卡顿。
